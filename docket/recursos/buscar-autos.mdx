# 🔐 Buscar por Número CNJ

Este endpoint inicia a extração de autos processuais sigilosos, acessando diretamente os sistemas dos tribunais — como ESAJ, PJe, Eproc, Projudi — com o login (usuário e senha) ou o certificado digital A1 do advogado que possui acesso ao processo.

---

## 🔗 Endpoint

```
POST https://api.predictus.com.br/predictus-api/processos/judiciais/autos/buscarPorNumeroCNJ
```

---

## 📥 Corpo da requisição

Com usuário e senha:

```json
{
  "numeroProcessoUnico": "50379103520218130702",
  "sistema": "EPROC-TRF2",
  "usuario": "52998224725",
  "senha": "senhaSegura",
  "tokenMFA": "GI2GGYZQGY3GMZRSG44TQOJTGUYWIZJV",
  "email": "redirecionamento@cliente.com",
  "modoAnexos": "MOVIMENTACOES"
}
```

Com certificado A1:

```json
{
  "numeroProcessoUnico": "50379103520218130702",
  "sistema": "PJE-TJMG",
  "certificado": "MIIKcQIBAzCCCi0GCSqGSIb3DQEHAaCCCh4Eggoa...",
  "senhaCertificado": "senhaDoCertificado",
  "tokenMFA": "GI2GGYZQGY3GMZRSG44TQOJTGUYWIZJV",
  "modoAnexos": "AUTOS_COMPLETOS"
}
```

---

## 📌 Campos obrigatórios

| Campo                 | Descrição                                                               |
| --------------------- | ----------------------------------------------------------------------- |
| `numeroProcessoUnico` | Número do processo no formato CNJ, com 20 dígitos (sem traços ou pontos) |
| `sistema`             | Código do sistema judicial — valor inválido retorna `400`. Veja a [lista de sistemas](../overview#sistemas-suportados) |

---

## 🔑 Login: escolha **uma** das formas

Envie **ou** `usuario` + `senha` **ou** `certificado` + `senhaCertificado`. Enviar as duas formas na mesma requisição retorna `400`.

| Forma | Campos | Sistemas |
| ----- | ------ | -------- |
| Usuário e senha | `usuario` — credencial de login (CPF, OAB ou e-mail, conforme o sistema). `senha` — senha de acesso ao sistema. Nenhum dos dois pode ser vazio | Todos |
| Certificado A1 | `certificado` — arquivo do certificado A1 (`.pfx` ou `.p12`) em base64, até 64 KB. `senhaCertificado` — senha do certificado. Nenhum dos dois pode ser vazio | `PJE-*` (exceto `PJE-TRT*` e `PJE-TST`) e `EPROC-*` |

O certificado é conferido antes de iniciar a captura. Se ele não abrir com a senha informada, não tiver chave privada ou estiver fora da validade, a resposta é `400` e a consulta não é cobrada.

---

## 🧩 Campos condicionais

Estes campos são opcionais no geral, mas **obrigatórios conforme o sistema alvo** — a API valida antes de tentar o login e responde `400`:

| Campo      | Quando é obrigatório                                                        | Erro se faltar |
| ---------- | --------------------------------------------------------------------------- | -------------- |
| `tokenMFA` | Sistemas com 2FA via aplicativo OTP (TOTP) — ver coluna **Tipo de 2FA** na [tabela de sistemas](../overview#sistemas-suportados). Vale também no login por certificado | `O tokenMFA é obrigatório para o sistema {sistema}` |
| `email`    | Sistemas cujo 2FA chega por e-mail (todos os `ESAJ-*`, além de `STF` e `TUCUJURIS-TJAP`) — precisa ser um e-mail válido | `O email é obrigatório para o sistema {sistema}` |

Nos demais sistemas, enviar `tokenMFA` ou `email` é inofensivo: o robô simplesmente ignora.

> ℹ️ Se o sistema exigir **2FA por e-mail**, o campo `email` **é obrigatório**. Esse e-mail deve estar com redirecionamento automático configurado para: [**predictus-docket@mailbox.org**](mailto:predictus-docket@mailbox.org).\
> Você pode criar uma **regra automática** (recomendado) ou reenviar manualmente o código recebido — mas atenção: o código expira em **menos de 1 minuto**, então é **fundamental** que a entrega seja rápida.

---

## 📎 Campo opcional: `modoAnexos`

Aceito apenas em `PJE-*` (exceto `PJE-TRT*` e `PJE-TST`) e `EPROC-*`. Em outro sistema, retorna `400`.

| Valor | O que é recuperado |
| ----- | ------------------ |
| `MOVIMENTACOES` | Os documentos de cada movimentação, em `movimentos[].anexo`. É o padrão quando o campo não é enviado |
| `AUTOS_COMPLETOS` | Além disso, os autos completos gerados pelo tribunal, em PDFs, na lista `documentos` do processo |

Os autos completos de processos grandes podem levar **dezenas de minutos** para ficar prontos: continue consultando o resultado enquanto o status for `PROCESSING`.

---

## ✅ Respostas possíveis

| Código | Significado                                  |
| ------ | -------------------------------------------- |
| `200`  | Solicitação iniciada — veja o corpo abaixo   |
| `400`  | Payload inválido — CNJ fora do padrão, sistema desconhecido, login em branco ou duplicado, certificado inválido, `modoAnexos` não aceito no sistema, ou falta do `tokenMFA`/`email` exigido pelo sistema |
| `401`  | Token de acesso à API inválido ou expirado   |
| `503`  | Não foi possível iniciar a captura agora — tente de novo após os segundos indicados no header `Retry-After` |

Corpo da resposta `200`:

```json
{
  "id": "892d7822-ea43-4209-90f9-a66f8b983f7b",
  "dataSolicitacao": "2026-11-25T14:32:10.512",
  "sistema": "PJE-TJMG",
  "numeroProcessoUnico": "50379103520218130702"
}
```

Login, senha, certificado ou token incorretos **não** voltam aqui: a solicitação é aceita e o resultado sai com status `BAD CREDENTIALS`.

---

## 📦 Após iniciar

Use o `id` e o `sistema` da resposta para acompanhar e consultar os autos:

➡️ [Buscar Resultado](./buscar-resultado)

> ⚠️ **Atenção**: Nos sistemas com 2FA via e-mail, o advogado deve configurar o redirecionamento automático para o endereço fornecido pela Predictus. O campo `email` na requisição ajuda a identificar e correlacionar corretamente o token recebido.
