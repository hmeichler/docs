# 📦 Buscar Resultado dos Autos

Este endpoint retorna o status atual da solicitação iniciada com [`buscarPorNumeroCNJ`](./buscar-autos).  
Quando finalizado com sucesso, disponibiliza os links para download dos documentos.

---

## 🔗 Endpoint

```
POST https://api.predictus.com.br/predictus-api/processos/judiciais/autos/buscarResultado
```

---

## 🧾 Corpo da requisição (exemplo)

```json
{
  "id": "892d7822-ea43-4209-90f9-a66f8b983f7b",
  "sistema": "ESAJ-TJSP"
}
```

---

## 📥 Exemplo de resposta com sucesso

```json
{
  "data": [
    {
      "numeroProcessoUnico": "50379103520218130702",
      "sistema": "PJE-TJMG",
      "grauProcesso": 1,
      "tribunal": "TJ-MG",
      "classeProcessual": {
        "nome": "[CIVEL] CUMPRIMENTO DE SENTENCA",
        "codigoCNJ": "12078"
      },
      "movimentos": [
        {
          "nomeOriginal": ["JUNTADA DE PETICAO DE MANIFESTACAO DA ADVOCACIA PUBLICA"],
          "anexo": [
            {
              "titulo": "MANIFESTACAO DA ADVOCACIA PUBLICA",
              "extensao": "PDF",
              "nomeArquivo": "manifestacao.pdf",
              "caminho": "https://link-assinado-temporario"
            }
          ]
        }
      ]
    }
  ],
  "message": "OK",
  "status": 200
}
```

Com `modoAnexos` igual a `AUTOS_COMPLETOS`, cada processo traz também a lista `documentos`, com os PDFs dos autos completos no mesmo formato de `anexo`:

```json
"documentos": [
  {
    "titulo": "Autos completos - parte 1",
    "extensao": "pdf",
    "nomeArquivo": "50379103520218130702-001.pdf",
    "caminho": "https://link-assinado-temporario"
  }
]
```

---

## 📌 Campos obrigatórios

| Campo     | Descrição                                                  |
| --------- | ---------------------------------------------------------- |
| `id`      | O `id` devolvido por `buscarPorNumeroCNJ`                  |
| `sistema` | O mesmo `sistema` enviado em `buscarPorNumeroCNJ`          |

---

## ✅ Códigos de resposta

| Código | Significado |
| ------ | ----------- |
| `200`  | Resposta com o status da solicitação (tabela abaixo) e, em `OK`, os documentos |
| `201`  | `PENDING` — ainda não há resultado para esse `id` e `sistema`. Consulte de novo em alguns segundos. Se continuar em `PENDING` por muito tempo, confira se o `id` e o `sistema` são os da solicitação |
| `401`  | Token de acesso à API inválido ou expirado |

---

## 🔄 Status possíveis

| Status | Descrição                                |
|--------|--------------------------------------------|
| `PROCESSING` | Consulta em andamento               |
| `OK`         | Autos recuperados com sucesso        |
| `BAD CREDENTIALS` | Login, senha, certificado ou OTP inválidos |
| `SPECIAL ERROR` | Processo em segredo de justiça  |
| `WRONG CAPTCHA` / `UNKNOWN ERROR` | Falha técnica no tribunal |

---

## 📄 Notas

- Os links retornados ficam disponíveis por até **24 horas**.
- Os arquivos são PDFs extraídos diretamente do portal judicial oficial.
- Com `AUTOS_COMPLETOS`, processos grandes podem ficar em `PROCESSING` por dezenas de minutos enquanto o tribunal gera os autos.
