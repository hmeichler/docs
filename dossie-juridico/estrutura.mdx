# 🧾 Estrutura de Dados - Dossiê Jurídico

Abaixo estão listados todos os campos retornados pelo endpoint de Dossiê Jurídico, com suas descrições, origem e obrigatoriedade.

## 📑 Tabela de Campos

| Campo                                           | Descrição                                                                                                                                                                                                                                                                                                                                                 |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `urlProcesso`                                   | URL do site do tribunal consultado                                                                                                                                                                                                                                                                                                                        |
| `numeroProcessoUnico`                           | Número único do processo - padrão CNJ definido para processos digitais a partir de 2015                                                                                                                                                                                                                                                                   |
| `numeroProcessoAntigo`                          | Número do processo anterior ao padrão CNJ - anterior a 2015                                                                                                                                                                                                                                                                                               |
| `statusObservacao`                              | Status do processo fornecido pela fonte consultada - campo não padronizado, pode variar de tribunal para tribunal e alguns tribunais não trazem essa informação, por isso, a Predictus apenas espelha a informação quando ela existe. Para substituir e padronizar o campo de status, a Predictus disponibiliza o campo `statusPredictus.statusProcesso`. |
| `grauProcesso`                                  | Grau/instância do processo (1, 2, 3 ,4)                                                                                                                                                                                                                                                                                                                   |
| `juiz`                                          | Nome do Juiz do processo                                                                                                                                                                                                                                                                                                                                  |
| `relator`                                       | Nome do Relator do processo                                                                                                                                                                                                                                                                                                                               |

| `orgaoJulgador`                                 | Órgão julgador (vara)                                                                                                                                                                                                                                                                                                                                     |
| `unidadeOrigem`                                 | Comarca ou unidade da vara                                                                                                                                                                                                                                                                                                                                |
| `classeProcessual`                              | Classe processual padronizada                                                                                                                                                                                                                                                                                                                             |

| `partes.dataAtualizacao`                        | Data da última atualização da parte                                                                                                                                                                                                                                                                                                                       |
| `partes.advogados`                              | Lista de advogados da parte                                                                                                                                                                                                                                                                                                                               |
| `partes.advogados.tipo`                         | Tipo do advogado                                                                                                                                                                                                                                                                                                                                          |
| `partes.advogados.nome`                         | Nome do advogado                                                                                                                                                                                                                                                                                                                                          |
| `partes.advogados.cpf`                          | CPF do advogado                                                                                                                                                                                                                                                                                                                                           |
| `partes.advogados.dataAtualizacao`              | Data da última atualização do advogado                                                                                                                                                                                                                                                                                                                    |
| `partes.advogados.oab`                          | OAB do advogado                                                                                                                                                                                                                                                                                                                                           |
| `partes.advogados.oab.uf`                       | UF da OAB                                                                                                                                                                                                                                                                                                                                                 |
| `partes.advogados.oab.numero`                   | Número da OAB                                                                                                                                                                                                                                                                                                                                             |
| `advogadosSemParte`                             | Advogados sem parte relacionada                                                                                                                                                                                                                                                                                                                           |
| `advogadosSemParte.tipo`                        | Tipo do advogado                                                                                                                                                                                                                                                                                                                                          |
| `advogadosSemParte.nome`                        | Nome do advogado                                                                                                                                                                                                                                                                                                                                          |
| `advogadosSemParte.cpf`                         | CPF do advogado                                                                                                                                                                                                                                                                                                                                           |

| `processosRelacionados`                         | Lista de outros processos relacionados a este |
| `processosRelacionados.numeroProcesso`          | Número do processo relacionado |
| `processosRelacionados.origemRelacao`           | De onde vem a relação: **TRIBUNAL** = o site do tribunal declara a relação, em qualquer um dos dois processos (confiança alta); **AGREGADO** = relação inferida pela Predictus, a partir do número do processo citado nas movimentações e de partes em comum (confiança média, pode conter ruídos).
