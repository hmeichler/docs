# 🧪 Busca Customizada (Parâmetros Avançados)

Este endpoint permite montar consultas altamente refinadas para encontrar processos judiciais com base em **características específicas**, como:

- Partes e advogados envolvidos (ou explicitamente não envolvidos)
- Valor da causa, datas, status, classe, assuntos
- Órgãos julgadores, julgamentos, juízes, relatores e mais
- Listas de números de processo (consulta em lote)

Retorna até **50.000 processos por chamada** (padrão: 10.000).

---

## 🔗 Endpoint

```
POST https://api.predictus.com.br/predictus-api/processos/judiciais/buscarPorParametros
```

## 📚 Campos importantes

- `partes` e `naoPartes` — lista de objetos com `cpf`, `cnpj`, `raizCnpj`, `nome`, `nomeExato`, `polo`\
  Permite incluir ou excluir partes específicas na consulta
  - `nome` — busca pela **frase** no nome da parte (encontra variações que contenham o termo)
  - `nomeExato` — busca o nome **exatamente** como cadastrado no tribunal
  - Informe `nome` **ou** `nomeExato`, não os dois
- `advogados` e `naoAdvogados` — filtro por **um** entre `cpf`, `oab` (`numero` + `uf`), `nome` ou `nomeExato`
  - Encontra o advogado tanto vinculado a uma parte quanto registrado no processo sem parte associada (`advogadosSemParte`)
  - Com `polo` informado, considera apenas advogados vinculados a uma parte daquele polo
- `numerosProcessoUnico` — lista de números de processo (até 10.000) para consulta em lote
- `classesProcessuais`, `assuntosCNJ`, `statusProcessuais`, `ramosDoDireito`, `segmentos` — todos os filtros padronizados Predictus
- `orgaosJulgadores`, `unidadesOrigem`, `tribunais` — filtros estruturais do processo
- `valorCausa` — faixa sobre o **valor da causa** (`valorCausa.valor`) (menorQue/menorIgualQue/maiorQue/maiorIgualQue). Considera **somente** o valor da causa: processo sem valor da causa não entra quando este filtro é usado.
- `valorExecucao` — faixa sobre o **valor de execução** fixado na decisão (`statusPredictus.valorExecucao.valor`), no mesmo formato de `valorCausa`. Usado junto com `valorCausa`, o processo precisa atender aos dois.
- `dataDistribuicao`, `dataArquivamento`, `dataTransitoJulgado` — permitem busca por faixa (menorQue/menorIgualQue/maiorQue/maiorIgualQue)
- `julgamentos` — resultado da sentença (ex: "IMPROCEDENCIA", "PROCEDENCIA EM PARTE")
  - Ver [lista completa de julgamentos](../../referencias/julgamentos)
- `ufs` — siglas de estado (ex: "SP", "RJ", "SC")
- `dataDistribuicao` — **obrigatório**, exceto quando a busca já é específica: com `numerosProcessoUnico`, documento de parte (`cpf`, `cnpj` ou `raizCnpj`) ou advogado por `cpf` ou OAB completa (`numero` + `uf`)
- `limiteResultados` — mínimo: 1 / máximo: **50.000** (padrão: 10.000)
- `camposRetorno` — escolha os campos desejados no retorno
- `naoNumerosProcessoUnico` - excluir processos específicos no retorno

---

## 📌 Como funcionam os filtros

| Situação                                               | Comportamento                                |
| ------------------------------------------------------ | -------------------------------------------- |
| Filtros diferentes                                     | Lógica **AND** entre eles                    |
| Listas internas (ex: classes)                          | Lógica **OR** dentro do array                |
| `naoPartes`, `naoAdvogados`, `naoNumerosProcessoUnico` | Excluem registros com as condições indicadas |
| Faixas (`data`, `valor`)                               | Deve estar dentro do intervalo fornecido     |

---

## 🧾 Códigos de resposta

| Código | Significado                     |
| ------ | ------------------------------- |
| `200`  | Sucesso — processos encontrados |
| `204`  | Nenhum processo encontrado      |
| `400`  | Erro de validação no payload    |
| `401`  | Token inválido ou expirado      |

---

## 🛡️ Validações

- `dataDistribuicao` ausente sem um filtro específico (ver acima) → `400`
- `limiteResultados` entre 1 e 50.000
- `numerosProcessoUnico` e `naoNumerosProcessoUnico`: até 10.000 itens cada, com números válidos
- `partes`, `naoPartes`, `advogados`, `naoAdvogados`, `assuntosCNJ`, `naoAssuntosCNJ`: até 100 itens cada
- Parte com `nome` e `nomeExato` ao mesmo tempo → `400`

## 💡 Quando usar

- Estudo de jurisprudência
- Análise de padrões de decisão
- Filtragem de massa com múltiplas variáveis
- Diagnóstico jurídico por perfil de risco ou estratégia

Retorna uma lista de objetos do tipo [`processo`](../estrutura), com todos os campos solicitados em `camposRetorno`.
