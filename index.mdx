## 🔍 API Judicial Predictus: velocidade, profundidade e inteligência em cada consulta

A Predictus é a maior referência em Inteligência Jurídica por trás das melhores decisões, com a maior base de processos judiciais do Brasil.

Com a API Judicial mais rápida do mercado, seus sistemas acessam, em menos de 3 segundos, informações de uma base com mais de **790 milhões de processos judiciais**, estruturados, atualizados e tratados para apoiar decisões críticas.

Nossa tecnologia permite integrar inteligência jurídica diretamente às suas operações, identificar riscos, compreender históricos e ampliar a visibilidade sobre pessoas e empresas com velocidade, precisão e escala.

> 🎯 **Predictus. Para decisões que exigem mais.**

## 🧩 Tipos de Pesquisa

A API Predictus aceita múltiplos tipos de input:

- **CPF/CNPJ**
- **Nome/Razão Social**
- **Número do Processo (CNJ)**
- **Nome, CPF ou OAB do advogado**
- **Filtros customizados por classe, assunto, valor, tribunal e data**
- **Temas especiais (ex: Recuperação Judicial do dia)**

---

## 📘 Glossário Rápido

| Termo             | Significado                                                                 |
|-------------------|------------------------------------------------------------------------------|
| **NPU**           | Número único do processo (formato CNJ)                                       |
| **Polo Ativo**    | Parte autora (quem entrou com a ação)                                        |
| **Polo Passivo**  | Parte ré (quem está sendo processado)                                       |
| **StatusPredictus** | Status interpretado com base nas movimentações: tramitação, recurso, arquivado, etc. |
| **Ramo do Direito** | Classificação padronizada (ex: cível, trabalhista, penal...)               |
| **Valor de Execução** | Valor final da condenação ou sentença monetária                          |
