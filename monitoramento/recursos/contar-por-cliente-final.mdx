# 🔎 Contar por Cliente Final

Este endpoint retorna uma linha por `clienteFinal` com entidades ativas, com o total e a quantidade por tipo. As linhas vêm em **ordem alfabética**, em páginas de até **1.000 clientes finais**.

Entidades sem `clienteFinal` aparecem numa linha com `clienteFinal: null`.

---

## 🔗 Endpoint

```
GET https://api.predictus.com.br/predictus-api/monitoramento/contagem/porClienteFinal
```

---

## 📚 Parâmetros

| Parâmetro | Obrigatório | Descrição |
|-----------|-------------|-----------|
| `cursor` | Não | Valor de `proximoCursor` da página anterior. Omita na primeira página |

---

## 📥 Exemplo de cURL

```bash
curl --location 'https://api.predictus.com.br/predictus-api/monitoramento/contagem/porClienteFinal' \
--header 'Authorization: Bearer {accessToken}'
```

---

## ✅ Resposta esperada (200)

```json
{
  "clientesFinais": [
    {
      "clienteFinal": null,
      "total": 12,
      "porTipo": { "EMPRESA": 0, "PESSOA": 12, "ADVOGADO": 0, "PROCESSO": 0 }
    },
    {
      "clienteFinal": "escritorio-0042",
      "total": 318,
      "porTipo": { "EMPRESA": 3, "PESSOA": 15, "ADVOGADO": 0, "PROCESSO": 300 }
    }
  ],
  "proximoCursor": null
}
```

| Campo | Descrição |
|-------|-----------|
| `clientesFinais[].clienteFinal` | O cliente final (`null` = entidades sem cliente final) |
| `clientesFinais[].total` | Total de entidades ativas do cliente final |
| `clientesFinais[].porTipo` | Quantidade por tipo de entidade |
| `proximoCursor` | Cursor da próxima página. `null` = não há mais páginas |

---

## 🧾 Códigos de resposta

| Código | Significado |
|--------|-------------|
| `200` | Página retornada |
| `400` | Cursor inválido |
| `401` | Token inválido ou expirado |
| `403` | Conta sem a permissão `MONITORAMENTO_V2` |

---

## 💡 Dica

> Uma chamada por página traz a carteira inteira agrupada por cliente final — útil para conferir o volume monitorado de cada um dos seus clientes.
