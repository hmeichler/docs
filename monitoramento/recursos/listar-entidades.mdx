# 🔎 Listar Entidades

Este endpoint lista as entidades ativas da sua conta, **em ordem de cadastro**, em páginas de até **10.000 entidades**.

Para saber apenas **quantas** entidades você tem, use [Contar Entidades](./contar-entidades) — é bem mais leve que percorrer a listagem.

---

## 🔗 Endpoint

```
GET https://api.predictus.com.br/predictus-api/monitoramento/entidades
```

---

## 📚 Parâmetros

| Parâmetro | Obrigatório | Descrição |
|-----------|-------------|-----------|
| `cursor` | Não | Valor de `proximoCursor` da página anterior. Omita na primeira página |
| `clienteFinal` | Não | Só entidades com este `clienteFinal` (valor exato) |
| `referenciaExterna` | Não | Só entidades com esta `referenciaExterna` (valor exato) |
| `situacao` | Não | `ACOMPANHANDO` ou `AGUARDANDO_CAPTURA`. Restringe a entidades `PROCESSO` naquela situação |

---

## 📥 Exemplo de cURL

```bash
curl --location 'https://api.predictus.com.br/predictus-api/monitoramento/entidades?clienteFinal=escritorio-0042&referenciaExterna=pasta-778&situacao=ACOMPANHANDO' \
--header 'Authorization: Bearer {accessToken}'
```

Mínimo (primeira página, sem filtros):

```bash
curl --location 'https://api.predictus.com.br/predictus-api/monitoramento/entidades' \
--header 'Authorization: Bearer {accessToken}'
```

Próxima página:

```bash
curl --location 'https://api.predictus.com.br/predictus-api/monitoramento/entidades?clienteFinal=escritorio-0042&cursor=eyJpZCI6MTAwMDB9' \
--header 'Authorization: Bearer {accessToken}'
```

---

## 🧾 Códigos de resposta

| Código | Significado |
|--------|-------------|
| `200` | Página retornada (pode vir vazia) |
| `400` | Cursor ou `situacao` inválidos |
| `401` | Token inválido ou expirado |
| `403` | Conta sem a permissão `MONITORAMENTO_V2` |

---

## 💡 Dica

> O cursor é opaco: use exatamente o valor recebido, sem montá-lo. Entidades cadastradas durante a paginação aparecem nas últimas páginas.

> Use `situacao=AGUARDANDO_CAPTURA` para ver quais processos cadastrados ainda não estão na base da Predictus.
