# 🔎 Remover Entidades

Este endpoint remove de **1 a 1.000 entidades** por chamada, pelos `entidadeId`. A remoção é **tudo ou nada**.

A entidade removida para de gerar eventos na hora. Cadastrá-la de novo recomeça o monitoramento do zero: o que aconteceu enquanto ela esteve removida não é notificado.

---

## 🔗 Endpoint

```
POST https://api.predictus.com.br/predictus-api/monitoramento/removerEntidades
```

---

## 🧾 Corpo da requisição

```json
{
  "entidadeIds": [
    "6f1c2a9e-0b7d-4c1e-9f3a-2d4b5c6e7f80",
    "0a9b8c7d-6e5f-4a3b-2c1d-0e9f8a7b6c5d"
  ]
}
```

---

## 📚 Campos

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `entidadeIds` | lista de UUID | Sim | De 1 a 1.000 `entidadeId`, sem repetição |

---

## 📥 Exemplo de cURL

```bash
curl --location 'https://api.predictus.com.br/predictus-api/monitoramento/removerEntidades' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {accessToken}' \
--data '{
  "entidadeIds": [
    "6f1c2a9e-0b7d-4c1e-9f3a-2d4b5c6e7f80",
    "0a9b8c7d-6e5f-4a3b-2c1d-0e9f8a7b6c5d"
  ]
}'
```

---

## ✅ Resposta esperada (200)

```json
{ "removidas": 2 }
```

---

## 🧾 Códigos de resposta

| Código | Significado |
|--------|-------------|
| `200` | Remoção concluída |
| `400` | Corpo inválido, ou id inexistente / de outra conta (com `invalidos`). Nada foi removido |
| `401` | Token inválido ou expirado |
| `403` | Conta sem a permissão `MONITORAMENTO_V2` |

---

## 🛡️ Validações

- Tudo ou nada: se um id for inválido, nada é removido.
- Id **já removido** conta como sucesso, então repetir a chamada após um timeout é seguro.
- Não existe remoção de todas as entidades da conta de uma vez.

---

## 💡 Dica

> Para remover todas as entidades de um cliente final, liste-as com [Listar Entidades](./listar-entidades) `?clienteFinal=` e remova os ids em lotes de até 1.000.
